# Données locales

Aucune donnée opérationnelle n'est committée. Les fichiers que tu utilises sur ta machine vont
dans ce dossier : Git les ignore tous, sauf ce README.

Le schéma des données de la carte actuelle est dans [docs/donnees.md](../docs/donnees.md). Les
données fictives arriveront avec le premier modèle, dans `backend/fixtures/`, chaque titre marqué
`FICTIF`.
