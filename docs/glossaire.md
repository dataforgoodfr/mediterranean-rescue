# Glossaire

Les mots du métier, et leur nom dans le code. Le code reprend ces mots : une notion nouvelle
s'ajoute ici avant d'entrer dans un modèle. Le glossaire de référence est celui de
SOS MEDITERRANEE : https://www.sosmediterranee.org/glossary/

Une définition te semble fausse ou floue ? Ouvre une issue `docs` : c'est une bonne première
contribution.

## Les opérations

| Mot | Dans le code | Sens |
|---|---|---|
| Opération | `Operation` | Une action en mer racontée par SOS MEDITERRANEE : sauvetage, transfert, évacuation médicale, incident, naufrage. |
| Sauvetage | `rescue` | Des personnes en détresse sont mises en sécurité à bord du navire. |
| Transfert | `transfer` | Des personnes passent d'un bateau à un autre. |
| Interception | `interception` | Une embarcation arrêtée en mer par des garde-côtes et ramenée vers le pays de départ. |
| Débarquement | `disembarkation` | L'arrivée à terre des personnes secourues, dans le port assigné. |
| Évacuation médicale | `medevac` | Une personne est évacuée pour être soignée à terre. |
| Naufrage | `shipwreck` | Une embarcation coule ou chavire. |
| Morts et disparus | `dead_missing` | Personnes décédées ou portées disparues lors d'un événement. |
| Personnes secourues | `people` | Le nombre de personnes mises en sécurité. Inconnu : vide, jamais zéro. |
| Publiée | `published` | Une personne a vérifié la source : l'opération peut apparaître sur la carte. |
| Journal de bord (logbook) | | Les pages publiques de sosmediterranee.org qui racontent chaque opération. |
| Rotation | | Une sortie en mer du navire, du départ au retour au port. |

## Le sauvetage en mer

| Sigle | Nom complet | Sens |
|---|---|---|
| SAR | Search and Rescue | La recherche et le sauvetage en mer. |
| SRR | Search and Rescue Region | Une zone de recherche et sauvetage, dont un État coordonne les secours. |
| MRCC | Maritime Rescue Coordination Centre | Le centre qui coordonne les secours dans une SRR. |
| POS | Place of Safety, lieu sûr | Le lieu où le sauvetage prend fin et où les personnes débarquent. |

## Les navires et les positions

| Mot | Sens |
|---|---|
| Ocean Viking | Le navire affrété par SOS MEDITERRANEE. |
| AIS | Automatic Identification System : le signal radio par lequel un navire donne sa position, son cap et sa vitesse. |
| MMSI | Le numéro à neuf chiffres qui identifie un émetteur AIS. |
| Mille nautique | 1 852 mètres. |
| Eaux territoriales | La bande de mer jusqu'à 12 milles nautiques des côtes. |
| WGS84 | Le système de coordonnées des GPS : latitude et longitude en degrés. C'est celui du projet. |
